# Card Game Visual Design Guide

> **Status:** Approved visual direction  
> **Purpose:** Source of truth for card art direction, borders, icons, logo, card back, and future web app styling  
> **Tone:** Epic, playful, readable, slightly cartoony fantasy  
> **Influence:** Premium fantasy trading card games, without copying any existing game 1:1

---

## 1. Core Visual Direction

The game should feel like a child's original monster-and-weapon world elevated into a polished fantasy card game.

The visual identity should balance:

- Epic fantasy presentation
- Chunky, readable shapes
- Slightly cartoony proportions
- Magical ornamentation
- Strong silhouettes
- Clear card-family differences
- High readability at physical card size
- Enough personality to feel collectible

The cards should feel exciting and premium without becoming overly dark, realistic, or complicated.

### Design Principles

- Readability comes before ornament.
- Card type should be recognizable before reading the card text.
- Icons should be simple enough to understand at a glance.
- Borders should feel magical, forged, carved, or crafted rather than photorealistic.
- Monster cards should reserve meaningful space for lore.
- Weapons should feel heroic and energetic.
- Special cards should feel rarer and more magical.
- The Black Hole and Infinity Beast should visually break the normal rules in a controlled way.

# 2. Color System

## Monster Palette

Monsters use a cool gray-blue and gray-purple identity.

| Token | Hex | Usage |
| --- | --- | --- |
| Miststeel Blue | `#6F8098` | Primary Monster frame color |
| Storm Slate | `#4C5E74` | Dark structure, shadows, banners |
| Duskmist Purple | `#7A6C8D` | Magical accents, crystals, highlights |
| Shadow Violet | `#5A5068` | Secondary dark purple accent |

### Monster Feel

- Cool
- Mysterious
- Magical
- Ancient
- Slightly strange
- Powerful without feeling evil by default

---

## Weapon Palette

Weapons use warm orange, yellow, and brass-gold tones.

| Token | Hex | Usage |
| --- | --- | --- |
| Ember Orange | `#E67A2E` | Primary Weapon accent |
| Golden Relic | `#F2C24C` | Bright highlight, energy, icon emphasis |
| Brass Gold | `#B98A3D` | Metallic trim, borders, medallions |

### Weapon Feel

- Warm
- Forged
- Heroic
- Energetic
- Crafted
- Powerful

---

## Shared Neutral Palette

These colors help unify all card families.

| Token | Hex | Usage |
| --- | --- | --- |
| Parchment | `#E7DCC7` | Lore boxes, description areas, neutral panels |
| Charcoal Ink | `#2D2A32` | Body text, dark trim, shadows |
| Ancient Steel | `#9EA5AE` | Neutral metal, shared UI structure |

---

## Special / Void Palette

| Token | Hex | Usage |
| --- | --- | --- |
| Void Core | `#261E3C` | Black Hole, Infinity Beast, rare/special accents |

Use Void Core sparingly so it retains visual importance.

Recommended support accents:

- Deep violet glow
- Blue-violet highlights
- Small orange/gold contrast points
- Black-to-purple gradients
- Cosmic or portal-like energy

# 3. Card Families

The game has three main visual families.

## Monster Cards

### Identity

Gray-blue, gray-purple, stone, crystal, mist, and magical metal.

### Recommended Motifs

- Carved stone
- Cool forged metal
- Mist
- Crystals
- Purple magical energy
- Blue highlights
- Slightly irregular fantasy geometry
- Creature-specific decorative details

Monster frames should feel sturdy and ancient without becoming gritty or horror-focused.

---

## Weapon Cards

### Identity

Orange, yellow, brass-gold, warm forged metal, and ember energy.

### Recommended Motifs

- Forged metal
- Gold trim
- Ember glow
- Sunburst forms
- Orange crystal details
- Hammered metal
- Radiant energy

Weapon cards should be visually warmer and brighter than Monster cards.

---

## Special Cards

Special cards include:

- Draw 1
- Draw 2
- Black Hole

### Draw Cards

Draw cards should feel like magical utility cards.

Suggested direction:

- Dark neutral or mixed frame
- Orange and purple highlights
- Motion
- Sparks
- Magical cards
- Portals
- Energy bursts
- Clear `DRAW 1` or `DRAW 2` typography

### Black Hole

The Black Hole should look immediately unique and more powerful than a normal Weapon.

Recommended direction:

- Void Core dominant
- Deep purple
- Cosmic swirl
- Portal or vortex imagery
- Very little parchment
- Small gold/orange highlights
- Strong central silhouette
- High contrast

---

# 4. Monster Card Anatomy

Monster cards should follow a consistent information hierarchy.

## Top Area

### Card Name

- Large display type
- Centered or nearly centered
- High contrast
- Short enough to scan quickly

### Point Medallion

- Clearly visible near the top edge
- Circular or gem-based badge
- Use `1`, `2`, or `3`
- Infinity Beast uses `∞`

The point value should be readable immediately from across the table.

---

## Main Art Window

This should be the largest visual region of the card.

Monster art should:

- Clearly show the creature
- Prioritize silhouette
- Avoid overly busy backgrounds
- Use dynamic poses
- Feel adventurous rather than gruesome
- Support the cool blue-purple palette without forcing every monster to be the same color

The monster should feel like the star of the card.

---

## Weapon Requirement Row

Place the required weapon icons directly beneath the art.

Example:

`Requires: [Grenade] [Spear] [Sword]`

Guidelines:

- Use icons whenever possible
- Keep icon size consistent
- Keep the row visually separated from lore text
- Use a dark backing strip for contrast
- Requirements should be readable without relying on full text labels

---

## Lore / Description Box

Every Monster card should reserve a meaningful parchment-like area for lore.

This section may eventually contain:

- 2-4 short lines of lore
- Personality
- Behavior
- Where the monster lives
- A humorous detail
- A short legend or story

The lore box should remain large enough that the card never feels cramped.

---

# 5. Weapon Card Anatomy

Weapon cards use the same general structural rhythm as Monster cards but should visually feel distinct.

## Top Area

- Weapon name
- Optional small weapon category label
- Warm forged-metal frame

Weapon cards do **not** need point medallions.

---

## Main Art Window

The weapon should dominate the illustration.

Recommended:

- Strong silhouette
- Slightly exaggerated proportions
- Dynamic fantasy lighting
- Simple background
- Warm highlights

Avoid overly realistic catalog-style depictions.

---

## Type / Rules Strip

A narrow information strip may sit beneath the art.

Examples:

- `WEAPON`
- `WEAPON • RANGED`
- `WEAPON • MELEE`
- `SPECIAL WEAPON`

This is mainly useful for future expandability.

---

## Description Box

Weapon cards should also retain a parchment description area.

This can eventually hold:

- Flavor text
- Short rules clarification
- A tiny bit of worldbuilding

Even mechanically simple weapons should feel like part of the same universe.

---

# 6. Weapon Icon System

Weapon icons must be:

- Bold
- Instantly recognizable
- Readable at small size
- Consistent in visual weight
- Slightly stylized
- Mostly silhouette-driven

Use dark circular or medallion-shaped icon containers with warm Weapon accents.

## Bow

- Traditional fantasy bow
- Strong curved silhouette
- Visible string
- No excessive detail

## Grenade

The Grenade icon should resemble a **modern hand grenade** rather than a cartoon bomb.

Recommended visual traits:

- Segmented or textured grenade body
- Visible safety lever
- Visible pull ring
- Compact silhouette
- Slight fantasy stylization is acceptable

Avoid:

- Round bomb-with-fuse imagery
- Cannonball silhouettes
- Overly military realism

The goal is immediate recognition while remaining consistent with the game's illustrated fantasy style.

## Mace

- Short handle
- Large spiked head
- Strong silhouette
- Slight exaggeration encouraged

## Sword

- Classic straight blade
- Simple guard
- Strong readable blade shape
- Slight heroic/fantasy styling

## Spear

- Long shaft
- Large pointed spearhead
- Strong diagonal silhouette
- Avoid overly ornate details

## Gun

The Gun icon should read as a **rifle**, not a pistol.

Recommended visual traits:

- Clear stock
- Long barrel
- Rifle silhouette
- Magazine or central body mass
- Modern-inspired shape with light fantasy stylization

Avoid:

- Handgun or revolver silhouettes
- Futuristic sci-fi blasters unless the game's art direction later evolves that way
- Excessive tactical detail

The rifle should be immediately identifiable when shown at small size.

## Black Hole

- Circular vortex
- Purple or violet core
- Strong spiral motion
- Minimal detail
- Distinct from all physical Weapon icons

---

# 7. Border System

Borders should use a shared construction language so all cards clearly belong to the same game.

## Shared Border Traits

- Thick outer silhouette
- Soft beveling
- Layered metal or carved-stone construction
- Slight surface wear
- Decorative corners
- Central top and bottom focal details
- No photorealistic material rendering
- No overly thin filigree

The style should feel handcrafted and magical.

---

## Monster Border

Recommended materials:

- Stone
- Steel
- Blue-gray metal
- Purple crystal
- Cool blue gems

Suggested corner details:

- Crystal shards
- Stone wedges
- Small purple inlays

Bottom crest:

- Blue or purple gem
- Diamond shape preferred

---

## Weapon Border

Recommended materials:

- Brass
- Gold
- Warm steel
- Orange enamel or crystal

Suggested corner details:

- Ember shapes
- Sunburst forms
- Forged metal plates

Bottom crest:

- Sun or flame-inspired medallion
- Orange/gold center

---

## Special Border

Recommended materials:

- Dark steel
- Blackened metal
- Violet crystal
- Gold edge highlights

The frame should visually bridge Monster and Weapon palettes while feeling rarer.

---

# 8. Card Back

The card back should combine the Monster and Weapon identities into one unified symbol.

## Primary Structure

Recommended composition:

- Deep blue-purple background
- Central swirling vortex
- Gold/orange energy ring
- Blue crystal accents
- Dark metal outer frame
- Strong vertical symmetry
- Small corner ornamentation

The card back should feel mysterious but welcoming.

It should visually say:

> Monsters, weapons, adventure, and possibility all exist inside this deck.

---

## Card Back Rules

- Must be rotationally neutral enough that players cannot identify card orientation.
- Avoid readable text unless the logo is intentionally centered.
- Keep the outer border dark enough to hide minor print wear.
- Central symbol should remain recognizable at thumbnail size.
- Avoid excessive tiny detail.

---

# 9. Logo Direction

The logo should combine major motifs from the game.

Possible elements:

- Central vortex or portal
- Weapon silhouettes
- Star or compass point
- Crystal accents
- Orange/gold energy
- Blue-purple core

The logo should feel:

- Adventurous
- Bold
- Magical
- Slightly cartoony
- Collectible
- Easy to reproduce digitally

The wordmark should use large, chunky fantasy lettering rather than delicate medieval calligraphy.

---

# 10. Typography

Typography should prioritize clarity and personality.

## Display / Card Name Font

Desired characteristics:

- Bold fantasy serif or semi-serif
- Adventurous
- Slightly chunky
- High readability
- Not overly medieval

Use for:

- Card names
- Major labels
- Logo support typography

---

## Body / Lore Font

Desired characteristics:

- Clean serif or readable humanist sans-serif
- Excellent readability at small sizes
- Comfortable for 2-4 lines of copy

Use for:

- Lore
- Card descriptions
- Rules text
- Supporting labels

---

## Numbers

Point values and major numbers should use:

- Heavy weight
- Simple shapes
- Strong contrast
- Large medallion treatment

The number should be readable before any other small text.

---

# 11. Illustration Style

Illustrations should be consistent across the game.

## General Style

- Stylized fantasy illustration
- Slightly exaggerated
- Painterly but clean
- Strong silhouettes
- Vibrant lighting
- Cinematic composition
- Not photorealistic
- Not childish clip-art
- Not grimdark

Think:

**Saturday-morning imagination presented with premium fantasy-card production value.**

---

## Monsters

Monster designs can be:

- Weird
- Funny
- Dangerous
- Cute in an odd way
- Huge
- Mechanical
- Animal-like
- Alien
- Magical

The original monster names and ideas should drive the art.

We should preserve the sense that these creatures came from the game's original creator rather than forcing them into traditional fantasy archetypes.

---

## Weapons

Weapon art should be stylized versions of recognizable objects.

The six standard weapons are:

- Bow
- Grenade
- Mace
- Sword
- Spear
- Gun / Rifle

Even modern-inspired items such as the Grenade and Rifle should be illustrated using the same fantasy-cartoon rendering style as the rest of the game.

---

# 12. Infinity Beast

The Infinity Beast should be visually unique.

It is:

- The dedicated Sudden Death Monster
- Worth `∞`
- Defeated using:
  - Grenade
  - Sword
  - Gun / Rifle

Recommended direction:

- Larger sense of scale
- Void or cosmic influence
- Mix of blue-purple monster palette with controlled orange/gold energy
- Stronger frame ornamentation
- `∞` point medallion
- Special border or additional glow
- More dramatic art than normal monsters

It should still clearly belong to the same game.

---

# 13. Web App Translation

The physical card visual system should translate directly into the future web app.

## Suggested CSS Tokens

```css
:root {
	/* Monsters */
	--monster-miststeel: #6F8098;
	--monster-storm-slate: #4C5E74;
	--monster-duskmist: #7A6C8D;
	--monster-shadow-violet: #5A5068;

	/* Weapons */
	--weapon-ember: #E67A2E;
	--weapon-golden-relic: #F2C24C;
	--weapon-brass: #B98A3D;

	/* Neutrals */
	--parchment: #E7DCC7;
	--charcoal-ink: #2D2A32;
	--ancient-steel: #9EA5AE;

	/* Special */
	--void-core: #261E3C;
}
```

## Digital Usage

Monster UI:

- Blue-purple active states
- Cool borders
- Crystal accents

Weapon UI:

- Orange-gold active states
- Warm borders
- Ember accents

Special UI:

- Purple/void treatment
- Controlled gold highlights

Neutral game areas:

- Charcoal
- Parchment
- Steel

The web app should feel like the cards have come to life rather than using a separate unrelated UI design language.

# 15. Design Checklist

Before approving any new card design, confirm:

- [ ] Card family is immediately recognizable
- [ ] Name is easy to read
- [ ] Main illustration has a strong silhouette
- [ ] Weapon requirements are easy to identify
- [ ] Icons remain readable at physical card size
- [ ] Monster card has enough lore space
- [ ] Border does not overpower the artwork
- [ ] Point value is easy to see
- [ ] Colors match the approved palette
- [ ] Art feels cartoony and epic rather than photorealistic
- [ ] Card still feels like part of the same game
- [ ] Grenade icon uses the modern hand-grenade design
- [ ] Gun icon uses the rifle design
