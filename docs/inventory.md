# Game Card Inventory & Monster Requirements

This document defines the current physical card inventory, Weapon distribution, Action-card distribution, Monster requirements, and scoring for the **core Monster Mania set**.

The core set follows the standard game format:

* 18 Weapon cards
* 5 Action cards
* 1 Ultimate Weapon card
* 17 regular Monster cards
* 1 dedicated Sudden Death Monster

Future expansions may replace or mix in different cards while preserving these category totals unless an expansion specifically changes deck construction.

---

# Player Draw Deck

The game uses one shared Draw deck containing **24 cards**.

## Weapon Cards

There are **3 copies of each core Weapon card**.

| Weapon  | Copies |
| ------- | -----: |
| Bow     |      3 |
| Grenade |      3 |
| Mace    |      3 |
| Sword   |      3 |
| Spear   |      3 |
| Gun     |      3 |

**Total Weapon cards: 18**

## Action Cards

The core set currently contains two Action-card definitions.

| Action | Copies |
| ------ | -----: |
| Draw 1 |      3 |
| Draw 2 |      2 |

**Total Action cards: 5**

Draw 1 and Draw 2 use the normal Action-card rules. They are played during the Action Phase, may be chained, and cards drawn through them are immediately available to play.

Future sets may use different Action cards while keeping the standard total of **5 Action cards**.

## Ultimate Weapon

| Card       | Copies |
| ---------- | -----: |
| Black Hole |      1 |

**Total Ultimate Weapon cards: 1**

The Black Hole can defeat any regular face-up Monster by itself.

The Black Hole cannot defeat The Infinity Beast and is removed from play before Sudden Death begins.

Future sets may use a different Ultimate Weapon while keeping the standard total of **1 Ultimate Weapon**.

## Total Shared Draw Deck

| Category        | Cards |
| --------------- | ----: |
| Weapon cards    |    18 |
| Action cards    |     5 |
| Ultimate Weapon |     1 |
| **Total**       | **24** |

For the core set, that total is:

```text
18 Weapons
+ 3 Draw 1
+ 2 Draw 2
+ 1 Black Hole
= 24 cards
```

# Monster Deck

The normal game contains **17 regular Monsters**.

There is **1 copy of each Monster** in the current core set.

The standard game fixes the total at 17 regular Monsters, but it does **not** require every compatible set to use the same number of 1-point, 2-point, and 3-point Monsters.

The following distribution is specific to the current core set.

# Core Monster Totals

The current core Monster deck contains:

* 11 × 1-point Monsters
* 5 × 2-point Monsters
* 1 × 3-point Monster

**Total regular Monsters: 17**

**Total available points in the current core set: 24**

Because the current core set contains 24 total regular-game points, a two-player game can end in a 12–12 tie and trigger Sudden Death.

A future compatible Monster mix may contain a different distribution of point values. The standard requirement is the total of **17 regular Monsters**, not this exact 11 / 5 / 1 split.

---

# Sudden Death Monster

The Infinity Beast is the core set's dedicated Sudden Death Monster and is **not shuffled into the regular Monster deck**.

| Monster            | Required Weapons      | Value              |
| ------------------ | --------------------- | ------------------ |
| The Infinity Beast | Grenade + Sword + Gun | Infinite / Victory |

## Infinity Beast Rules

The Infinity Beast appears only when two or more players are tied for the highest score after all regular Monsters have been defeated.

During Sudden Death:

* Only tied players participate.
* The Ultimate Weapon is removed from the game.
* Maximum hand size is reduced from 5 cards to 4 cards.
* Action cards continue to function normally.
* The Infinity Beast requires Grenade + Sword + Gun.
* The first player to defeat The Infinity Beast immediately wins.

The Infinity Beast does not add numeric points to a player's normal score. Its **Infinite Points** presentation represents immediate victory.
