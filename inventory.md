# Game Card Inventory & Monster Requirements

This document defines the current card inventory, weapon distribution, Monster requirements, and scoring for the base game.

---

# Player Draw Deck

The game uses one shared Draw deck containing **24 cards**.

## Standard Weapons

There are **3 copies of each standard Weapon card**.

| Weapon  | Copies |
| ------- | -----: |
| Bow     |      3 |
| Grenade |      3 |
| Mace    |      3 |
| Sword   |      3 |
| Spear   |      3 |
| Gun     |      3 |

**Total standard Weapon cards: 18**

## Draw Cards

| Card   | Copies |
| ------ | -----: |
| Draw 1 |      3 |
| Draw 2 |      2 |

**Total Draw cards: 5**

## Special Weapon

| Card       | Copies |
| ---------- | -----: |
| Black Hole |      1 |

The Black Hole can defeat any normal Monster by itself.

The Black Hole is removed from play during Sudden Death.

## Total Shared Draw Deck

* 18 standard Weapon cards
* 3 Draw 1 cards
* 2 Draw 2 cards
* 1 Black Hole

**Total: 24 cards**

# Normal Game Totals

The regular Monster deck contains:

* 11 × 1-point Monsters
* 5 × 2-point Monsters
* 1 × 3-point Monster

**Total Monsters: 17**

**Total available points: 24**

Because 24 is even, a two-player game can end in a 12–12 tie, which triggers Sudden Death.

---

# Sudden Death Monster

The Infinity Beast is a dedicated Monster and is **not shuffled into the normal Monster deck**.

| Monster            | Required Weapons      | Value              |
| ------------------ | --------------------- | ------------------ |
| The Infinity Beast | Grenade + Sword + Gun | Infinite / Victory |

## Infinity Beast Rules

The Infinity Beast appears only when two or more players are tied for the highest score after all normal Monsters have been defeated.

During Sudden Death:

* Only tied players participate.
* The Black Hole is removed from the game.
* Maximum hand size is reduced from 5 cards to 4 cards.
* The Infinity Beast requires Grenade + Sword + Gun.
* The first player to defeat The Infinity Beast immediately wins.

The Infinity Beast does not actually add points to a player's normal score. Its **Infinite Points** value represents an immediate victory.
